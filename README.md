# 북마크 보관함

X(트위터) 북마크를 카테고리·폴더로 정리하는 도구입니다.

---

## 시작하는 방법

### 1. 확장프로그램으로 북마크 추출
`X 북마크 내보내기` (확장프로그램)을 설치해서 북마크를 `.csv`로 추출합니다.
[확장프로그램 다운로드](https://posty.pe/p7zi7fpc)

### 2. CSV를 `.bookmark` 폴더에 넣기
추출한 `.csv` 파일을 레포의 `.bookmark/` 폴더에 넣습니다. 앱에서 **[불러오기]** 를 누르면 이 폴더의 CSV를 모두 가져옵니다.

다른 위치의 파일은 **[다른 경로]** 로 고르면 됩니다.

트위터 내보내기 CSV뿐 아니라 노션에서 보낸 CSV(`Name`, `URL`, `Tags`)도 같은 불러오기로 넣을 수 있습니다.

## 다운로드

[Releases](../../releases) 페이지에서 최신 버전을 받으세요.

| 파일 | 설명 |
|------|------|
| `북마크정리기 Setup x.x.x.exe` | Windows 설치형 |
| `북마크정리기 x.x.x.exe` | Windows 포터블 (설치 불필요) |
| `북마크정리기-x.x.x.dmg` | macOS (Intel + Apple Silicon) |

또는 [브라우저](https://min4sang.github.io/BMBOX)에서 바로 사용할 수도 있어요. 브라우저에서는 `.bookmark` 기본 경로를 쓸 수 없고, 다른 경로 불러오기만 됩니다.

## 설치 시 보안 경고 안내

### Windows
설치 시 **"Windows가 이 앱을 차단했습니다"** 라는 파란 경고창이 뜰 수 있어요.

> **추가 정보** 클릭 → **실행** 클릭

이후엔 정상적으로 설치돼요.

### macOS
처음 실행 시 **"개발자를 확인할 수 없어서 열 수 없습니다"** 라는 경고가 뜰 수 있어요.

> `.dmg`를 열어 앱을 응용 프로그램 폴더에 복사한 뒤,  
> **Finder에서 앱 우클릭 → 열기 → 열기** 클릭

한 번만 이렇게 허용하면 이후엔 정상적으로 실행돼요.

---

## 업데이트

앱 실행 시 새 버전이 있으면 우측 하단에 알림이 떠요.  
**[설치하기]** 를 누르면 자동으로 다운받고 재시작 후 업데이트됩니다.

---

## 참고
- 데이터는 앱/브라우저에 자동 저장됩니다.
- 백업: **환경설정 → 백업 내보내기(.json)**
- `.bookmark` 안의 CSV는 git에 커밋하지 않습니다.
